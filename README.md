# StudyGen AI – AI-Based Notes and Quiz Generator

## About the Project
StudyGen AI is a web-based educational application that helps students generate concise study notes and interactive quizzes from uploaded learning materials using Generative AI.

## Features
- User login and signup
- Upload study materials in supported file formats
- AI-generated study notes
- Multiple-choice quiz generation
- Adjustable quiz difficulty and question count
- Interactive quizzes with scoring and answer review
- Quiz history and performance dashboard
- Download study notes as PDF
- Local fallback when the AI service is unavailable

## Technologies Used
- Python
- Flask
- Gemini API
- HTML and CSS
- JavaScript
- SQLite

## Setup
1. Install Python.
2. Install the required packages using `requirements.txt`.
3. Create a `.env` file and add your Gemini API key using the variable `GEMINI_API_KEY`.
4. Run the Flask application using `python app.py`.
5. Open the local address shown in the terminal.

## Security
Do not upload API keys, passwords, virtual environments, or private user data to the repository.

## Purpose
The project aims to make studying, revision, and self-assessment easier through AI-assisted learning.
